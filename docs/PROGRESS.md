**M1 범위 밖에서 먼저 붙인 것: 바깥 필드.** 게임은 필드의 고양이 항구에서 시작한다. 필드는 6×6 조각을 이어 붙인 지도
(설산·숲·마을·가을 숲·바다·사막)이고, 이정표 34곳 앞에 포탈이 있다. 그중 13곳이 던전으로 이어진다 (나머지는 흐린 포탈, 연결 전).
던전의 빛나는 칸으로 나오면 그 포탈 앞으로 돌아온다. 필드는 전투 없이 자유 이동이고, **지형에 따라 움직임이 바뀐다** —
길·풀밭은 걷기, 숲은 도끼, 물은 배, 눈밭은 높이 걷기, 모래밭은 힘주어 걷기. 고양이 머리 위에 감정 아이콘이 뜬다.
지형 마스크는 아직 가운데 판(한 장 지도 시절 지도)에만 있다.

### 2026-10-01 · 낚시 입질·당기기 패턴 다양하게

사용자: "찌를 찌르는 타이밍이 세 번으로 똑같다." — 전에는 "톡톡 n번(0.8~1.7초 간격) → 쏙" 한 가지였다.
- **입질 패턴 7가지**: 톡톡 · 연타 · 찌올림 · 끌고가기 · 한방 · 헛잠김 · 망설임. 물고기가 찌를 노리는 순간 가중치로 하나를 골라
  신호 순서를 미리 짠다(`commitBite`). 진짜 입질 모양도 셋(쏙 · 찌올림 · 끌고가기) — 떠오르거나 끌리는 건 눈에 잘 보이는 대신 챔질 시간 ×1.15/×1.35,
  한방은 ×0.9. 망설임은 30% 로 그냥 가 버린다 (실패 아님). 시간은 물고기가 찌에 붙어 있을 때만 흐른다.
- 종마다 성격: 피라미 연타·잔걸음, 붕어 찌올림·꾸준, 퍼치 한방/끌고가기·지그재그, 송어 한방·점프, 메기 헛잠김·묵직, 비단잉어 망설임·지그재그.
- **당기기 모양 5가지**: 간격·길이·속도 배율 + 지그재그(날뛰는 중 0.3~0.55초마다 방향을 홱, 선착장 쪽으로는 안 틈) +
  점프(날뛰기 시작에 0.4초 동안 장력 +0.3 — 감고 있으면 위험, "펄쩍!" · 그림자가 옅어짐).
- 실패 글자로 배우기: "헛잠김이었어요! 쏙 잠겨서 안 올라올 때 채요", "찌가 쑥 떠오른 게 입질이었어요!", "찌를 끌고 갈 때 채야 해요!" 등.
- 밸런스 약속을 node 체크로 고정: 사람 반응(0.3초 뒤 떼기)으로 모든 종 10/10 낚음, 별 1~2 는 계속 감아도 10/10, 별 3 이상은 계속 감으면 0/10.
  패턴 체크는 일부러 망가뜨린 코드(찌올림을 쏙으로 · 연타를 느리게)에서 실패하는 것 확인.

### 2026-10-01 · 호수섬 정박지 낚시 ★

사용자가 낚시 리소스(`art/fishing/`: 배경 · 고양이 6동작 · 그림자 6형태 · 잡은 물고기 6종 · 찌·효과 6종 + atlas/layout JSON)를 줬다.
"이동 없이 낚시만" 하는 고정 화면 — 리소스의 layout.json 흐름(던지기 → 입질 → 챔질 → 당기기 → 성공/실패)을 뼈대로, 단계마다 재미를 하나씩:
- **던지기 = 타이밍**: 누르고 있으면 조준 링이 줄었다 커졌다 한다(|cos|^1.6 — 가장 작은 언저리를 조금 길게). 떼는 순간 링 안 어딘가에 떨어진다.
- **노리기 = 눈치**: 물고기는 그림자로 돌아다닌다. 그림자가 클수록 크거나 귀하다(같은 종도 큰 개체는 크게). 바로 위에 던지면 놀라 도망가고
  (겁 많은 종일수록 멀리서), 앞쪽 가까이 던지면 다가온다. 전설(노을 비단잉어)은 그림자가 반짝이고, 나타나면 알림.
- **입질 = 참을성**: 톡톡(약한 입질)일 때 채면 "너무 일찍". 찌가 쏙 잠기면 종마다 정한 시간(0.45~0.8초) 안에 챈다. 빨리 채면 "완벽한 챔질".
- **당기기 = 줄다리기**: 장력이 1을 넘은 채 0.35초면 끊어짐, 너무 느슨한 채 2.2초면 바늘 빠짐. 물고기가 날뛸 때 계속 감으면 장력이 넘친다.
  기운이 다하면 "지쳤다! 쭉 감아요". 큰 물고기일수록 천천히 감긴다.
- **수집**: 도감 6칸(모르는 종은 실루엣), 크기 기록, NEW · 최고 기록 배지. 감정 아이콘(집중·놀람·힘주기·뿌듯·좌절·신남·눈부심)과 합성 효과음.
- **밸런스**(종마다 30판 시뮬레이션, 사람 반응 0.25~0.3초 가정): 별 1~2(피라미·붕어·퍼치)는 계속 감아도 낚인다(4~8초).
  별 3 이상(송어·메기·비단잉어)은 계속 감으면 30판 모두 끊어지고, 날뛸 때 놓으면 30판 모두 낚인다(11~13초 손맛).
  처음엔 날뛸 때 감는 장력이 약해 비단잉어도 그냥 감아 낚였다 → 0.75 → 0.9. 승부가 4~7초로 짧았다 → 무게(힘)에 따라 감는 속도↓,
  기운 소모 0.22 → 0.15, 챔질 뒤 첫 날뜀 1.6배로 거리를 벌림.
- 포탈: 호수섬 정박지 → 낚시터. 원래 호수섬에 있던 '섬' 전투장은 등대섬 정박지로 옮겼다 (바다 모래섬 그림이라 맞고, 안 옮기면 갈 길이 없다).
- 버그(새 검사로 발견): 호수 선착장(호숫가 전투장) 포탈의 돌아올 자리가 물 위였다 → 뭍으로. verify 에 "연결된 포탈의 돌아올 자리가 뭍" 추가.
- 검증: node 체크(던지기 정확도·놀람·너무 빠름/늦음/챔질·피라미는 계속 감아도·비단잉어는 감으면 끊어지고 놓으면 낚임·바늘 빠짐·도감),
  브라우저(실제 마우스로 물고기 앞에 던짐 → 저절로 온 입질 → 날뛸 때 놓으며 당김 → 낚음 → Space 다시 → Esc 필드 → 포탈로 재입장).

### 2026-10-01 · 미니맵은 둘러보기, 워프는 큰 화면의 포탈을 눌러서

사용자 제안: 미니맵에서 바로 워프하지 말고, 지도를 슬라이드해 둘러본 뒤 포탈을 눌러 이동.
- 미니맵을 누르거나 끌면 카메라가 그 지점으로 슬라이드한다 (고양이는 그대로). 큰 화면은 마우스로 끌어 민다.
- 큰 화면에서 포탈(빛 원·빛 기둥·이름표 언저리)을 끌지 않고 누르면 고양이가 그 포탈로 워프. 끌기와 누르기는 5px 로 가른다.
- 둘러보는 중에 방향키를 누르면 카메라가 고양이에게 부드럽게 돌아온다 (돌아오면 다시 고양이를 따라감).
- 카메라는 지도 밖을 보지 않게 가둔다 (끝 쪽 포탈은 화면 가운데까지 안 온다).
- verify: 실제 마우스로 미니맵 누르기 → 고양이 그대로·카메라 이동, 포탈 누르기 → 워프, 끌기 → 워프 아님, 방향키 → 카메라 복귀.

### 2026-10-01 · 클리어 후 못 움직이던 버그 · 포탈 그림 되돌림 · 미니맵 워프

- **버그: 방을 클리어하면 고양이가 못 움직여 나가는 칸까지 못 갔다.** 던전 로직이 "살아 있음"을 `phase === 'playing'` 으로 봐서
  `cleared` 가 되면 이동·펀치·구르기가 다 막혔다 (넉백으로만 조금 밀림). 단일 방 시절 코드부터 있던 것 — 검증의 탈출 테스트가
  몬스터가 살아 있을 때 걸어 나가서 못 잡았다. → 낮잠(`napped`)일 때만 막는다. 검증은 이제 **방을 비운 뒤** 걸어 나가고,
  node 체크에 "클리어 뒤 이동 · 낮잠이면 정지"를 넣었다 (둘 다 고치기 전 코드로 실패하는 것 확인).
- **포탈 그림**: 이벤트 시트의 포탈 그림이 너무 강하다는 사용자 의견으로 예전 단순한 빛 원 + 빛 기둥으로 되돌렸다.
- **미니맵**: 필드 오른쪽 위. 이정표 점을 누르면 그 포탈 위로 워프한다. 내리는 자리는 포탈 위치(`at`) — 검증이 뭍인지 보는 자리라
  물에 떨어지지 않고, 포탈 위에 내려도 한 번 벗어났다 들어와야 빨려 들어간다 (그 자리에서 바로 던전으로 가지 않음). 미연결 포탈에도 워프된다.
  배경은 조각 36장을 1/8 로 줄인 한 장(89KB)이라 큰 조각을 다 받지 않는다.

  예고는 예고 행 6칸을 예고 시간에, 타격은 공격 행 6칸을 0.42초에, 피격은 도망 행 앞 2칸(움찔), 쓰러짐은 도망 행 뒤 4칸(연기).
  스탯은 가족 기본값 + 변형(기본·A·B)마다 체력 ×1/×1.15/×1.35, B 는 공격 +2. 가족마다 한 변형은 원거리(화살은 아직 선 그림).
- **슬라이서 개선**: 몬스터 51종을 다 불러 보니 2종이 틀렸다. 얼음볏·방울 펭귄은 볏이 윗줄에 닿아 행이 5→4,
  갈매기 선원은 효과선 한 줄(24px)이 한 칸을 차지하고 대신 두 컷이 한 칸(458px)으로 합쳐졌다 (칸 수는 6이라 칸 수 검사로는 못 잡고 폭 검사로 잡힘).

  자동 슬라이서로 통일 — 좌표가 없는 필드 몬스터 30종에도 똑같이 적용되기 때문.
- **눈/모래 걷기**: 지역은 조각 단위(`field.json` `biomes`), 그 안에서 발밑 색으로 판정 (눈은 밝은 무채색, 모래는 모래색).
  모션만 바뀐다. 빙판 미끄러짐·모래 엉덩이 미끄럼 행은 아직 안 쓴다 (빙판·비탈 지형이 정해지면).

### 2026-09-29 · 지형 마스크를 RGBA 채널 형식으로

색 다섯 가지를 정확히 골라 칠하는 방식이 번거롭다는 사용자 요청으로, **채널 하나에 지형 하나**로 바꿨다.

| 채널 | 지형 | 칠하는 법 |
| --- | --- | --- |
| R | 막힘 (암석·절벽) | 흰색 = 막힘 |
| G | 숲 (도끼) | 흰색 = 숲 |
| B | 물 (배) | 흰색 = 물 |
| A | 다리 | **투명하게 지운 곳 = 다리** |

- 셋 다 검정·불투명 = 걷기. 채널마다 128 이상이면 칠한 것. 겹치면 **다리 > 막힘 > 물 > 숲** (강 위에 다리를 지우개로 뚫으면 물은 안 지워도 된다).
- **A 를 거꾸로 쓰는 이유**: A 흰색 = 다리로 두면 지도 대부분이 투명해지는데, 포토샵 등 편집기와 브라우저는 투명한 픽셀의 RGB 를
  버리거나 0 으로 만든다 → R·G·B 에 칠한 게 날아간다. 투명한 곳이 다리 몇 곳뿐이면 잃을 게 없다.
- 기존 마스크(손으로 칠한 다리 포함)는 그대로 옮겼다. 변환 전후 지형별 픽셀 수가 전부 같은 것을 확인.
- `node tools/terrain.mjs --preview` 가 채널별 흑백 보기(`tools/out/terrain-channels.png`)도 만든다.
- **생성기는 마스크가 이미 있으면 덮어쓰지 않고 멈춘다** (`--force` 일 때만 새 초안). 작업 중 셸이 기록 문장 속 명령을
  실행해 생성기가 돌면서 손으로 칠한 다리가 사라질 뻔했다 (백업으로 복원). 사용자가 다듬은 마스크도 같은 식으로 날아갈 수 있어서 막았다.


### 2026-09-28 · 필드 충돌(암석·절벽)과 다리

- **막는 건 암석·절벽뿐이다. 집·분수대는 걸어서 지나간다** (사용자 결정 — 처음엔 집도 막았다가 되돌렸다).
  초안 생성기(`tools/terrain.mjs`)는 "채도 낮은 회베이지 + 울퉁불퉁함(주변 밝기 편차)"으로 암석을 잡는다.
  광장 돌바닥은 평평해서 빠지고, 길 사이 돌계단은 양쪽이 흙길이라 빠진다. 집 벽·창틀도 이 규칙에 걸려서,
  지붕으로 집 영역을 찾아 **바위에서 빼는 데** 쓴다. 분수대 물은 배를 탈 물이 아니라 걷기, 폭포는 절벽이라 막힘.
- **다리** (처음엔 노랑, 지금은 A 채널 투명) — 배가 강을 따라가다 다리를 만나면 내리지 않고 그대로 넘어간다. 다리 밑 연출은 없다(사용자: 필요 없음).
  규칙: 배는 **물 아니면 다리 위에만** 선다. 앞길이 다리이고 그 너머(90px 안)에 다시 물이 있으면 넘어가고,
  다리가 아닌 땅(풀밭·모래)이면 내린다. 바위가 끼면 못 넘어간다. 다리 위에서 다리를 따라 옆으로는 안 간다.
  **모양만으로는 다리와 좁은 풀밭을 구별할 수 없어서 마스크에 다리 색을 따로 뒀다.**
- 초안의 다리 자동 인식은 약해서 **돌다리와 서쪽 나무다리 두 곳은 손으로 칠했다** (호수 → 강 → 아래 강이 배로 한 번에 이어진다).
  동쪽 나무다리는 바다 쪽 절벽 골짜기 위라 그 밑 강이 배로 이어지지 않아 칠하지 않았다.
- 걸을 때는 다리 = 걷기와 같다.
- `npm run verify` 가 두 다리를 양방향으로 배로 건너 보고, 시작점에서 모든 워프까지 갈 수 있는지(마스크로 입구를 막지 않았는지),
  암벽에 밀고 들어가면 멈추는지, 매 프레임 막힌 곳 위에 서지 않는지를 본다.
- 도끼질 타이머가 멈출 때마다 0 이 되던 것 수정 — 방향을 바꾸는 한 프레임 멈춤에도 초기화돼서 숲에서 지그재그로 걸으면 도끼를 안 휘둘렀다.

  ⚠ 한때 동작까지 3배 빠르게(0.15초) 잘못 바꿨다가 되돌렸다 — **동작 속도(`chopTime`)는 건드리지 않는다.**
  숲에서 속도 0.55배, 배 1.15배.
- **숲에서 발 앞을 가리는 수풀**: 배경이 그림 한 장이라 나무 뒤로 들어갈 수 없어서, 발밑의 배경 그림을 고양이 다리 위에
  가장자리를 부드럽게 다시 그린다. 같은 그림이라 따로 놀지 않는다.
- **소리**: 도끼 "탁", 배 타고 내릴 때 "첨벙", 노 저을 때마다 작은 "찰랑" (전부 Web Audio 합성).
- **필드 고양이 크기**: 사용자 요청으로 두 번 줄였다 — 75% (키 45.8 → 34px), 다시 50% (**17px**, `field.json` `catBody`).
  **크기를 바꿀 땐 `catBody` 한 값만 고친다.** 걷기·도끼·배 스프라이트, 그림자, 수풀, 배 간격(`modes.boat.offset`)·뱃머리(`bow`, 둘 다 고양이 키 배수),
  도끼로 친 지점, 나뭇잎·물보라·물결 크기와 속도가 전부 이 값에 비례한다. 걷는 속도는 지도 기준이라 크기와 따로 논다 — 50% 로 줄인 뒤 너무 빨라 보여서 30% 늦췄다 (170 → **119px/초**, `field.json` `speed`).
- **시트끼리 크기 맞추기**: 대기 행 키(`bodyH`)로 맞춘다. **배 시트만 예외** — 배를 크게 그리느라 고양이가 절반 크기라서,
  배 옆에 서 있는 컷(오르기 첫 컷·내리기 마지막 컷)의 키로 맞춘다. 대기 행으로 맞췄더니 내린 뒤 고양이가 두 배로 커졌다.
- 배는 오르내리는 동안 행 높이가 달라도(뛰는 고양이) 같은 크기로 그린다 (`rowScale` 1).
- 튜닝 값은 전부 `src/data/field.json`: `forestDelay` `boardTime` `modes.{walk,axe,boat}` (속도·도끼 주기·노 간격·배 offset·bow — offset·bow 는 고양이 키 배수).
- **스프라이트 시트 7장도 WebP 로** — Chrome 인코더는 알파를 무손실로 저장해서 칸 자르기 결과가 PNG 와 같다(알파 분포 동일,
  verify 6칸 통과). 시트 10.3MB → 2.75MB. **에셋 합계 3.3MB** (새 시트를 PNG 로 넣었으면 11.5MB 로 한도 초과였다).
  지형 마스크만 색이 정확해야 해서 PNG.

## 시트 슬라이서 (src/sheet.ts) — 시트를 바꿀 때 알아둘 것

1. 행: 가로 전체에 알파가 없는 줄로 나눈다.
2. 열: 행 안에서 알파가 없는 세로줄로 나눈다. **칼끝·주먹이 옆 칸에 닿으면 두 프레임이 붙어 한 칸이 된다**
   → 칸이 모자라면 가장 넓은 구간을 가운데 절반에서 알파가 가장 적은 열로 가른다.
3. 가로 기준점 = 프레임마다 **몸 무게중심**(전체 픽셀 x 의 중앙값). 공격 때 밀려나오지 않고, 돌아설 때 제자리.
4. 세로 기준점 = 행 단위 발바닥 중앙값 (프레임마다 재면 지면이 출렁인다).
5. 행 배율 = 행별 유효 높이로 정규화 (행마다 캐릭터 키가 최대 17% 다르다). 모션 전환 때 0.1초 보간.
6. 안전망: 없는 칸을 요청하면 마지막 칸을 그린다 (사라지지 않게).
7. 칸이 **많이** 잡히면: 점 노이즈(보통 조각의 15% 미만)는 버리고, 그래도 많으면 가장 가까운 조각끼리 합친다.
   배에서 내려 옆에 선 고양이처럼 한 프레임이 떨어진 두 조각일 수 있어서, 작은 조각을 그냥 버리면 안 된다.
8. 배 시트는 `anchor: 'hull'` — 바닥 40% 안 가장 긴 가로줄(선체) 가운데가 기준. 무게중심이면 고양이가 뛰어들 때 배가 미끄러진다.
9. 시트끼리 크기는 대기 행 키 `bodyH` 로 맞춘다 (배 시트 예외는 결정 기록 참고).

4. **장난감 5개** (M1 범위, GDD 7장) — 데이터는 `src/data/` JSON.
5. **무적 표시** — 깜빡임을 뺀 뒤 부활 무적(1.5초)이 안 보인다. 발밑 링 같은 다른 방식으로.
6. **치명타** (GDD 5% / 150%) — 데미지 숫자에 변화가 생긴다.
7. **조각 지형 마스크 — 사용자가 요청할 때 만든다** (지금은 가운데 4조각만 기존 마스크, 나머지는 빈 마스크 = 전부 걷기).
   요청이 오면 `tools/terrain.mjs` 를 조각 기준으로 고쳐 초안을 만들고, 사용자가 고친 마스크는 `src/assets/world/masks/mask_rR_cC.png` 에 넣고
   `npm run verify` 로 확인한다 (입구가 막혔는지, 다리가 끊겼는지 알려 준다).
   초안에서 손봐야 할 곳: 산 암벽이 얼룩덜룩(밝은 면이 빠짐), 해안 절벽 일부만 잡힘, 자갈 같은 작은 점, 숲 경계가 거칢.
8. 층 구조 — 지금은 포탈 하나에 방 하나. 던전 안에서 방을 여러 개 잇는 건 GDD 6장 맵 생성과 같이.

10. 8방향 스프라이트 — 지금은 좌우 반전만. 필드에서 위아래로 물에 들어가도 시트는 옆모습이다.
